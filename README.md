# fwkrumm.github.io

Source for personal GitHub Pages portfolio.

Main public portfolio content lives in [index.md](index.md) and is published on site homepage.

The homepage presents projects as connected language skill trees. Edit `trees`, `projects`, and `edges` in the front matter of [index.md](index.md) to maintain content and connections. Node positions live in [assets/css/skill-tree.css](assets/css/skill-tree.css); hover, keyboard, and touch interactions live in [assets/js/skill-tree.js](assets/js/skill-tree.js).

- Site: https://fwkrumm.github.io/
- Local preview notes: [docs/local_testing.md](docs/local_testing.md)

Repository exists to host and style page, not to duplicate portfolio content in two places.
